# Creator V2.1 — Thumbnails, Presets, Playback, Light Mode

**Date:** 2026-04-13
**Status:** Design approved
**Author:** Niki + Claude
**Builds on:** `2026-04-13-creator-v2-design.md`

## Vision

Four features that make the Creator feel complete: snapshot thumbnails give visual identity to scenes, curated presets provide instant creative starting points, sequencer playback makes the storyboard perform, and light mode gives the tool a second personality.

## Design Decisions

| Question | Decision | Rationale |
|----------|----------|-----------|
| Light mode depth | Full theme with CSS variable tokens | Token layer scales to custom themes later. Dark stays default, light transforms both UI and viewport. |
| Sequencer crossfade | Lerp all numeric params + layer fade | Universal interpolation primitive. Camera animation deferred. |
| Preset behavior | Destructive replace with auto-snapshot | Presets become sequencer building blocks. Nothing is ever lost. |
| Snapshot thumbnails | Screenshot on capture + palette strip | Lightweight, serializable, works in sequencer and save/load picker. |
| Build order | Thumbnails → Presets → Playback → Light mode | Each builds on the last. Thumbnails needed for preset auto-snapshot. Playback benefits from real presets to test with. |

## 1. Snapshot Thumbnails

### Capture System

When `takeSnapshot()` fires:
1. Grab the R3F canvas element via `gl.domElement`
2. Call `canvas.toDataURL("image/png", 0.5)` to produce a compressed data URL
3. Store it as `thumbnail: string` on the Snapshot object

### Store Changes

```typescript
// Snapshot type gains thumbnail field
export type Snapshot = {
  id: string;
  name: string;
  timestamp: number;
  thumbnail: string;   // data URL from canvas capture
  state: SerializedState;
};

// takeSnapshot gains optional thumbnail param
takeSnapshot: (name: string, thumbnail?: string) => void;
```

### Capture Utility

```typescript
// Utility function — called from CreatorPage before takeSnapshot
function captureCanvasThumbnail(): string {
  const canvas = document.querySelector("canvas");
  if (!canvas) return "";
  // Scale down for storage efficiency
  const tempCanvas = document.createElement("canvas");
  tempCanvas.width = 200;
  tempCanvas.height = 120;
  const ctx = tempCanvas.getContext("2d")!;
  ctx.drawImage(canvas, 0, 0, 200, 120);
  return tempCanvas.toDataURL("image/png", 0.5);
}
```

### Sequencer Node Update

Each scene card in `SequencerPanel.tsx` shows:
- Thumbnail as background image (cover, rounded corners)
- Scene number + name overlaid at bottom with semi-transparent backdrop
- Thin palette strip (3-5 color dots) below the card
- Fallback: palette dots if no thumbnail available

### Save/Load Picker Update

Saved scenes also store a representative thumbnail (captured at save time) for the load picker modal. The `SavedScene` type gains a `thumbnail: string` field.

### Behavior

1. Auto-capture thumbnail of current state
2. Auto-snapshot current state (preserves in sequencer)
3. Apply form via `setPreset(form)`
4. Set `layers` — enable/disable each layer, apply tuned params
5. Set `palette`
6. Set `postFX` — enable specific FX, disable others

### Store Changes


The `applyScenePreset` action:
1. Calls `takeSnapshot("Auto: before preset", thumbnail)` to auto-save
2. Calls `setPreset(formForPreset)` to generate nodes/edges
3. Sets `layers` to the preset's layer config (deep clone of defaults + overrides)
4. Sets `palette`
5. Sets `postFX`

## 3. Sequencer Playback

### PlaybackEngine Component

New file: `src/components/creator/three/PlaybackEngine.tsx`

An R3F component (renders null) that runs crossfade logic in `useFrame`:

```typescript
type PlaybackState = {
  phase: "idle" | "playing" | "crossfading";
  fromSnapshotId: string | null;
  toSnapshotId: string | null;
  progress: number;          // 0-1 during crossfade
  triggeredConnectionId: string | null;
  elapsedInScene: number;    // ms since entering current scene
};
```

### Playback Loop

Each frame when `isPlaying === true`:

1. **Idle/playing phase:** Increment `elapsedInScene` by delta. Evaluate all outgoing connections from `activeSnapshotId`:
   - `time` trigger: fire if `elapsedInScene >= trigger.delay`
   - `click` trigger: fire if a click event was forwarded from SceneInteraction
   - `paramThreshold` trigger: check current param value against threshold + direction
2. **First trigger to fire wins** — set `phase: "crossfading"`, record `fromSnapshotId`, `toSnapshotId`, `triggeredConnectionId`
3. **Crossfading phase:** Increment `progress` based on `transition.duration`. Each frame, lerp between `from` and `to` snapshot states:
   - Numeric params: linear lerp `from + (to - from) * progress`
   - Palette colors: lerp each RGB channel per slot
   - Layer enabled: if target has layer enabled but source doesn't, set enabled and lerp intensity from 0. Reverse at end.
   - `postFX`: snap to target values at progress 0.5
   - `seed`: snap (integer, no lerp)
   - `nodes`: match by index, lerp positions. Extras snap in/out at progress 0.5
4. **Crossfade complete** (progress >= 1): set `activeSnapshotId` to target, reset `elapsedInScene`, set `phase: "playing"`
5. **No outgoing connections:** loop current scene (stay in playing phase)
6. **Pause:** freeze `progress` and `elapsedInScene`

### Easing

Apply easing function to `progress` before lerping:
- `linear`: `p`
- `ease-in`: `p * p`
- `ease-out`: `1 - (1 - p) * (1 - p)`
- `ease-in-out`: `p < 0.5 ? 2 * p * p : 1 - (-2 * p + 2)^2 / 2`

### Store Changes

```typescript
// New state
playbackState: PlaybackState;

// New actions
setPlaybackState: (state: Partial<PlaybackState>) => void;
resetPlayback: () => void;
```

### SceneInteraction Integration

When `isPlaying` is true and a `click` trigger exists on an outgoing connection:
- SceneInteraction forwards the click to the playback engine (sets a ref or dispatches to store)
- Normal placement/drag is disabled during playback

### ThreeRenderer Update

Add `<PlaybackEngine />` inside `<AdaptiveQuality>`, after `<ModulationEngine />`.

## 4. Light Mode (CSS Theme Tokens)

### Token System

Define CSS custom properties on `:root` (dark default) and `.theme-light` override:

```css
:root {
  --bg-app: #09090b;
  --bg-panel: #111113;
  --bg-card: #18181b;
  --bg-hover: rgba(255,255,255,0.05);
  --bg-active: rgba(255,255,255,0.1);
  --border: #27272a;
  --text-primary: #e4e4e7;
  --text-secondary: #a1a1aa;
  --text-muted: #71717a;
  --text-dim: #52525b;
  --accent: #a78bfa;
  --success: #00ffa3;
  --off: #3f3f46;
  --viewport-bg: #09090b;
  --panel-blur: rgba(17,17,19,0.8);
}

.theme-light {
  --bg-app: #fafafa;
  --bg-panel: #ffffff;
  --bg-card: #f4f4f5;
  --bg-hover: rgba(0,0,0,0.04);
  --bg-active: rgba(0,0,0,0.08);
  --border: #e4e4e7;
  --text-primary: #18181b;
  --text-secondary: #52525b;
  --text-muted: #a1a1aa;
  --text-dim: #d4d4d8;
  --accent: #7c3aed;
  --success: #059669;
  --off: #d4d4d8;
  --viewport-bg: #f0f0f2;
  --panel-blur: rgba(255,255,255,0.8);
}
```

### Store Changes

```typescript
// New state
theme: "dark" | "light";

// New action
setTheme: (theme: "dark" | "light") => void;
```

Default: `"dark"`.

### UI Toggle

- Sun/moon icon button in the right panel header area (top-right, above SCENE PRESETS)
- Keyboard shortcut: `Cmd+Shift+L`
- Toggles `.theme-light` class on the root layout `<div>`

### Component Migration

Replace all hardcoded Tailwind color classes with CSS variable references:
- `bg-[#09090b]` → `style={{ background: "var(--bg-app)" }}`
- `text-[#a1a1aa]` → `style={{ color: "var(--text-secondary)" }}`
- `border-[#27272a]` → `style={{ borderColor: "var(--border)" }}`
- Or use Tailwind `bg-[var(--bg-app)]` syntax where supported

Files to migrate:
- `CreatorPage.tsx` — all panel styling
- `SequencerPanel.tsx` — all card/badge styling
- `LayerRow` (inside CreatorPage) — card backgrounds, text colors

### 3D Scene in Light Mode

`MeshGraph.tsx` reads `theme` from store:
- Dark: `<Environment preset="night" />`, point lights at current intensities
- Light: `<Environment preset="studio" />`, point light intensities reduced by 40%, add a soft directional light from above

`ThreeRenderer.tsx`:
- Canvas background: `var(--viewport-bg)` via style prop

Sphere materials in light mode (SphereCluster reads theme):
- Roughness +0.1 (less glossy, more matte)
- Emissive intensity -0.05 (less glow to avoid blowout on light bg)
- No transmission change (glass still looks good on light)
