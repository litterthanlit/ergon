ERGON — Design Specification

Review the full spec, then let me know what to revise

Identity
Bandcamp for generative art. A creative tool that happens to be a platform.
Brand voice: Precise. Quiet. Confident. Warm.
Core Product
The Studio
Hybrid editor — visual parameter layer on top, code editor underneath. Templates as starting points. Learning gradient: Explorer → Tweaker → Modifier → Creator.
Gallery → Immersive
Curated grid with editorial voice. Click a piece → signature transition → full-bleed live rendering. The platform disappears. The art takes over.
Design System

Body text
metadata

8px base unit

add more space
Business Model
Studio is free. Always. No tiers. No gates.
15% transaction cut when art sells (Bandcamp model). Artist gets 85%. Revenue aligned with artist success.
90-Day MVP
Month 1
The Studio — editor, sandbox, templates, parameter sync
Month 2
Publishing + Gallery — profiles, grid, immersive mode, transition
Month 3
Collecting + Polish — Stripe, editions, beta with 50 artists
Non-Negotiables for V1
1. Studio feels magic on first use (<3s to "whoa")
2. Signature transition is cinematic
3. Typography and spacing are impeccable
4. Art renders fast and looks sharp
