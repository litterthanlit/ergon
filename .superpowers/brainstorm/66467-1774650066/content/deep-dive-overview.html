4. Parameter Architecture (revised from spec)
Spec change: One-way sync, not bidirectional.
Artists declare params via ergon.params({...}). Platform generates UI controls. Controls send values at runtime via postMessage. Code never mutates from slider interaction. This achieves the same UX for 10% of the engineering effort.
